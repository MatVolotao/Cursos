Título Principal do Site

Este conteúdo serve como base para estudos de responsividade. A ideia é observar como o texto, os espaços e a imagem se adaptam em telas menores e maiores sem perder legibilidade.

Tópicos para estudar

  • Medidas relativas para tipografia e espaçamento
  • Estrutura semântica com seções e listas
  • Imagens responsivas com a tag picture

Como praticar

Teste aumentar e reduzir o zoom do navegador. Depois altere os valores de fonte e padding no CSS para perceber a diferença entre medidas absolutas e relativas.
